# إصلاح التوكن — الحقيقة كاملة

**التشخيص بعد الفحص الفعلي:**

```
[PASS] account id — format valid
[FAIL] token active — 1000: Invalid API Token
shape_problems: []
token_length: 53
```

## ما يعنيه هذا بالضبط

| المعطى | معناه |
|---|---|
| شكل القيمة سليم | لا علامات تنصيص، لا سطر جديد، لا مسافات |
| الطول **٥٣** | ⚠️ **توكنات Cloudflare طولها ٤٠ حرفًا بالضبط** |
| `1000 Invalid API Token` | Cloudflare لا تعرف هذه القيمة — أصلًا |

**الاستنتاج:** القيمة المخزّنة **ليست توكن Cloudflare**. الطول ٥٣ يطابق مفتاحًا من خدمة أخرى (مثل GitHub PAT أو مفتاح OpenAI) وُضع في الخانة الخطأ — أو أنه توكن أُضيف ثم أُعيد توليده، فبقيت نسخة قديمة.

كل التوكنات العشرة في لوحتك **صحيحة** — لكن **أيًّا منها ليس هو ما في المستودع**.

## لماذا لا يمكن استرجاع القديم

Cloudflare تعرض قيمة التوكن **مرة واحدة فقط** عند إنشائه. بعد ذلك لا توجد طريقة لرؤيته — لا في اللوحة ولا في أي مكان. ولهذا:

- ❌ لا يمكن "تصحيح" السرّ الحالي
- ✅ يجب **توليد قيمة جديدة** ولصقها

## الإصلاح — ٣ دقائق على الهاتف

### ١. اختر توكنًا موجودًا

افتح **https://dash.cloudflare.com/profile/api-tokens**

اختر **`Workers AI`** — الصلاحية التي تحتاجها للصور موجودة فيه أصلًا.

> إن كان لديك عدة توكنات باسم `Workers AI`، أيّها كان. الفرق بينها لا يهم.

### ٢. جدّده

اضغط **`...`** بجانبه ← **Roll**

ستظهر القيمة الجديدة **مرة واحدة**. اضغط **Copy** — أو انسخها بيدك.

**تحقق سريع:** القيمة الجديدة طولها **٤٠ حرفًا** بالضبط.
> إن كانت ٥٣ أو أي طول آخر — أنت تنسخ الشيء الخطأ.

### ٣. حدّث السرّ

**https://github.com/ghith93/raawaa-autonomous-engine/settings/secrets/actions**

اضغط **`CLOUDFLARE_API_TOKEN`** ← **Update** ← الصق ← **Save**

> ⚠️ أزل أي مسافة أو سطر جديد في نهاية القيمة.

### ٤. تحقق

سيعمل ملف العمل تلقائيًا. أو شغّله من:

**https://github.com/ghith93/raawaa-autonomous-engine/actions/workflows/raawaa-image-route-check.yml** ← **Run workflow**

## ما ستراه عند النجاح

```
[PASS] account id — format valid
[PASS] token active — status=active
[PASS] account access — account visible: ...
[PASS] D1 access — database found: raawaa-autonomous-e
```
ثم صورة ١٠٢٤×١٠٢٤ حقيقية في **Artifacts**.

## إن فشل مرة أخرى

| العلامة | المعنى | الحل |
|---|---|---|
| `length: 40` + `1000` | القيمة صحيحة الشكل لكنها ملغاة | جدّد توكنًا **آخر** (ربما جدّدت القديم بالفعل) |
| `length: 53` مرة أخرى | اللصق لم يُحدَّث | تأكد أنك ضغطت **Update** لا **Add** |
| `length: 41` أو 42 | سطر جديد في النهاية | الصق في محرّر نصوص أولًا ثم انسخ |
| `7003` | الحساب لا يطابق التوكن | التوكن من حساب آخر |
| `9109` | صلاحية ناقصة | أضف `Workers AI: Read` للتوكن |

## لماذا ٥٣ حرفًا مألوفة

| الخدمة | طول المفتاح |
|---|---|
| GitHub PAT (`ghp_`) | **40** + بادئة = **40–93** |
| OpenAI (`sk-proj-`) | **164** |
| Anthropic (`sk-ant-`) | **~108** |
| Stripe (`sk_live_`) | **~107** |
| **Cloudflare API Token** | **40 بالضبط** |

الطول ٥٣ يقع في نطاق مفاتيح GitHub. الحل هو نفسه في كل الحالات: قيمة جديدة من المصدر الصحيح.

# خريطة البنية التحتية — كل طبقة وبديلها

**القاعدة الحاكمة:** لا يوجد مكوّن واحد بلا بديل. إن فشل شيء، يعمل الذي بعده تلقائيًا.

---

## ١. توليد الصور — سلسلة من ثلاث طبقات

| # | المزوّد | التكلفة | متى يُستخدم | ما يحدث عند فشله |
|---|---|---|---|---|
| ١ | **Cloudflare FLUX** | $0 (١٧٣ صورة/يوم) | الأساس | ينزل للثاني |
| ٢ | **Qwen-Image-2512 محلي** | $0 بلا حد | إن وُجد GPU | ينزل للثالث |
| ٣ | **المولّد المحلي البسيط** | $0 دائمًا | اختبار الخط | لا يفشل أبدًا |

```bash
python scripts/raawaa_images.py --status     # ما هو متاح فعلًا الآن
python scripts/raawaa_images.py --prompt "..." --out shot.png
```

**ثلاث ضمانات في الكود:**
1. أي مزوّد سعره غير مؤكد **يُرفض** — لا يُعتبر مجانيًا.
2. سقف الـneurons اليومي يُفحص **قبل** الطلب، لا بعده.
3. عند استخدام البديل البسيط، يخرج الأمر بـ**exit 3** حتى لا يُفهم النجاح خطأً.

## ٢. طبقة التجارة — لأي منتج، ليس للسيروم

| الملف | يحل مشكلة | البديل إن لم تستخدمه |
|---|---|---|
| `money.py` | كسور الفلوس | تكتشف خطأ ٣ سنت بعد ٢٠٠ طلب |
| `orders.py` | "الطلب" ليس بيعًا | تحسب إيرادًا لم تقبضه |
| `delivery.py` | نسبة الرفض القاتلة | تسعّر بلا معرفة خسارتك |
| `offers.py` | العرض الكاذب | تُكشف وتفقد الحساب |
| `sourcing.py` | أرخص مورّد ≠ أفضل مورّد | تشتري بـMOQ لا تملكه |
| `unit_economics.py` | الربح بعد الرفض | تظن أنك تربح وأنت تخسر |
| `validation.py` | منتج غير قانوني | تُحظر أو تُغرَّم |
| `publishing.py` | النشر اليدوي المنسي | تنشر ٣ مرات وتتوقف |

```bash
python scripts/commerce.py doctor
python scripts/commerce.py sku --price 18 --cost 4.5 --delivery 2 --refusal 1
python scripts/commerce.py offers --check "خصم ٧٠٪"
python scripts/commerce.py product --config product.json
python scripts/commerce.py suppliers --config suppliers.json
```

## ٣. البدائل في القنوات

| القناة | الحالة | البديل |
|---|---|---|
| إنستغرام API | يحتاج حساب أعمال + رابط صور عام | **رفع يدوي** (يعمل دائمًا) |
| واتساب API | محظور في سوريا | رسائل يدوية |
| تيك توك | محظور في سوريا | — |
| إعلانات ميتا | مقيّدة من سوريا | تشغيل من الخارج |
| الدفع الإلكتروني | شام كاش شخصي | **الدفع عند الاستلام** |

> كل قناة معطّلة لها بديل يدوي يعمل. لا توجد قناة واحدة تقف عندها الدورة.



## ٥. ما يتبقى — حسب الأولوية

| # | العمل | من | الأثر |
|---|---|---|---|
| ١ | إضافة مفتاح Cloudflare | أنت (٢ دقيقة) | يفتح ١٧٣ صورة/يوم |

## ٦. ما لا يفعله النظام (بصراحة)

- **لا يكتب منشورًا بلا موافقتك.** النشر يحتاج `approve` صريحًا.
- **لا يخترع رقمًا.** كل رقم إما مُقاس أو معلن كمفقود.
- **لا يشغّل قناة محظورة.** يقول "غير متاح" فورًا بدل أن يفشل بعد ساعة.
